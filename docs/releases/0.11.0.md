# Wordlit 0.11.0

Dictionary 正式更名为 **Wordlit**。Chromium 扩展为 0.2.2，Obsidian 插件为 0.1.1；连接协议不变。
正式发行与实际文件以 [GitHub Releases](https://github.com/liyunhui0707/wordlit/releases) 为准。

## 本版变化

- 应用、菜单、设置、帮助、官网与扩展统一 Wordlit 品牌。
- 原创森林绿 W 与暖金光芒标识，用于原生图标、网站和扩展。
- 应用名为 `Wordlit.app`，新发行文件使用 `Wordlit-0.11.0-macOS-<架构>`。
- 更新器兼容原仓库及新仓库的严格地址校验、新旧安装包名称；不自动安装更新。
- 保留已有 Bundle ID、偏好设置键、密钥服务、配对令牌位置和连接端口。
  内部 `DictionaryApp` 名称是兼容标识，不能为品牌统一而清空或重建用户数据。

## 升级与回退

正常退出 Dictionary，再安装 Wordlit，只保留一个日常运行入口。
保留验证过的 Dictionary 0.10.0 安装包作为回退；旧版发行文件、标签和散列不改名或覆盖。
已加载的旧浏览器扩展可以继续连接；不要求为应用改名重新配对或更改快捷键。
导出到新路径可能产生新的 Chromium 扩展身份，因此不把新目录加载当作无损替换。

原版旧更新器可能拒绝改名后的 GitHub 地址。遇到检查更新失败时，直接通过
[浏览器下载页](https://github.com/liyunhui0707/wordlit/releases) 手动升级，不修改安全校验或系统权限。

## 质量与验证范围

本版没有修改捕获算法、翻译提示词、默认模型或发音行为。复用 0.10.0 已接受的阅读证据，
结合本批回归检查，不要求使用者重做旧例句。品牌迁移不能解决默认模型的已记录误译。

品牌源码阶段：481 项 Swift、130 项脚本／扩展回归和 12 项隐藏原生界面预览通过；
主窗口与设置明暗图像已生成并抽查。

继续采用 Apple Silicon / arm64、macOS 14+、临时签名、未经 Apple 公证及手动更新。
本版不以旧版样例或包完整性声称浏览器下载隔离首次打开、真人发音或语义质量全部通过。
